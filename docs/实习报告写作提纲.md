# 毕业实习报告写作提纲

> 写作时应结合自己真实的开发过程、截图、测试数据与问题记录补充，避免直接照搬模板。

## 一、实习目的与任务

- 说明毕业实习的时间、单位、岗位或项目背景。
- 项目题目：基于 Spring Boot 与 Milvus 的本地知识库文献智能检索系统设计与实现。
- 项目目标：解决本地文献数量增加后检索效率低、关键词表达不一致以及回答缺少来源的问题。

## 二、需求分析

### 2.1 用户需求

用户希望批量上传文献，通过自然语言提问获得答案，并能够查看答案所依据的原始片段。

### 2.2 功能需求

文献导入、文献解析、文本切片、向量存储、相似度检索、RAG 问答、来源展示、文献管理、历史记录和系统状态。

### 2.3 非功能需求

- 易用性：界面清晰，无需复杂操作。
- 可维护性：分层设计，核心能力以接口解耦。
- 可部署性：Docker Compose 一条命令启动。
- 安全性：密钥使用环境变量，文件名与页面输出进行安全处理。

## 三、技术调研

可分别说明 Spring Boot、Milvus、RAG、向量嵌入、余弦相似度、PDFBox、H2 和 Docker。建议使用自己的语言解释每种技术在本项目中的作用，不要只写定义。

- 说明为何选择单体分层架构。

图表可以参考《系统设计说明》中的 Mermaid 图，并在报告中重新绘制为学校要求的格式。

## 五、详细设计与实现

### 5.1 文献管理模块

说明批量上传、扩展名校验、UUID 存储名、文献状态和异常记录。

### 5.2 文本解析与切片模块

说明 PDFBox 提取文字、文本清洗、700 字符窗口与 120 字符重叠的设计理由。

### 5.3 向量检索模块

说明 Milvus 集合字段、384 维向量、AUTOINDEX、COSINE 和 Top-K 检索。

### 5.4 RAG 问答模块

说明“问题向量化 → 检索相关片段 → 组织上下文 → 生成答案 → 返回引用”的实现。

### 5.5 前端模块

展示工作台、上传页、问答页、来源面板和历史页截图，说明响应式适配。

## 七、问题与解决过程

可选择真实遇到的问题，例如：

- Milvus 首次启动较慢：增加健康检查与依赖等待。
- 向量维度不一致：固定配置并说明更换模型时需重建集合。
- 扫描 PDF 无法提取文字：识别为当前限制，将 OCR 列为后续扩展。
- 文本在切片边界语义不完整：采用重叠窗口并优先在标点处切分。
- 第三方模型额度影响演示：实现零密钥本地模式作为降级方案。
